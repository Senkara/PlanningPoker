# PlanningPoker

Backend-focused Planning Poker application built with Java, featuring a lightweight Swing GUI for interaction.

## Features
- Client-server architecture
- Real-time communication using Java Sockets
- Simple Swing GUI for voting and interaction
- Database persistence via JDBC
- Multi-user team estimation support

## Technologies
- Java
- Java Swing
- Socket Programming
- JDBC
- SQLite

## Architecture Overview
- Server handles rooms, voting logic and persistence
- Clients connect via sockets and interact through GUI
- JDBC layer manages database operations

## Purpose
This project was developed to strengthen backend development skills, focusing on networking, concurrency and database integration rather than frontend complexity.
